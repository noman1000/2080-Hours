Overtime & premium rules

Every hour worked starts at 1× (straight time). Rules are checked from top to bottom for each hour. At least raises the rate if it's lower, Add stacks on top of the current rate, and Set to replaces it. Tick Stop to skip every rule below once this one applies. For example, a field trip set to 1.75× with Stop never gets double time.
